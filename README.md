# Calendrier de l'année

Générateur de calendrier annuel (12 pages A4) : pleines lunes nommées, nouvelles lunes, jours fériés Vaud et Genève, plusieurs styles et palettes, une image par mois.

Site statique : ouvrir `index.html`, ou héberger le dossier tel quel. Impression : bouton « Imprimer / PDF » (A4, marges « Aucune », graphiques d'arrière-plan activés).

Tests des calculs (lune, jours fériés) : `node test.js`.
